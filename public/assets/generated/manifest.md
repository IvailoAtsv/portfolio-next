# Generated Portfolio Illustration Pack

The shipping rasters share one monochrome early sound-era cartoon system: confident black contour, expressive white gloves, warm ivory paper, restrained gray wash, and subtle print grain. The illustrations use object characters, with facial features drawn directly on each object's material rather than on an added face patch. The hero, four practice cels, and About portrait share one browser-window character. Each image has a readable action; material detail and purposeful surroundings give the scenes life. They contain no intended copy, logos, or watermarks. Navigation, headings, buttons, charts, screenshots, icons, and diagrams remain semantic page elements.

Exact final generation or edit prompts are stored beside each WebP as `.webp.json` sidecars. The illustrations were generated with built-in ImageGen, then converted to optimized WebP with Sharp. Keep Up preserves the original as an edit target. The other scenes developed from its ink-and-paper style, and About references the hero to preserve the browser character's identity. The hero received a final edit removing all generated typography. The practice sequence uses four separate digital-product cels so every action stays large, cheerful, anatomically clean, and fully visible at mobile sizes. Replaced source images remain recoverable in Git history.
