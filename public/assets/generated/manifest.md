# Generated Portfolio Illustration Pack

The shipping rasters share one monochrome early sound-era cartoon system: confident black contour, expressive white gloves, warm ivory paper, restrained gray wash, and subtle print grain. All five September 3 replacements use object characters, with facial features drawn directly on each object's material rather than on an added face patch. The hero and About portrait share one browser-window character. Each image has one readable action; material detail and purposeful surroundings give the scenes life. They contain no intended copy, logos, or watermarks. Navigation, headings, buttons, charts, screenshots, icons, and diagrams remain semantic page elements.

Exact final generation or edit prompts are stored beside each WebP as `.webp.json` sidecars. The September 3 replacements were generated with built-in ImageGen, then converted to optimized WebP with Sharp. Keep Up preserves the original as an edit target. The other scenes developed from its ink-and-paper style, and About references the new hero to preserve the browser character's identity. The hero received a final edit removing all generated typography. Replaced source images remain recoverable in Git history.
